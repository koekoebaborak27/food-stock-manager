# docs/development/ — 開発手順

| ファイル | 何が書いてあるか |
|---|---|
| [`本テンプレートPJをコピーする方法.md`](本テンプレートPJをコピーする方法.md) | ベースにした `ai-dev-template` から新しいプロジェクトのリポジトリを作る手順（`gh` CLI を使う方法・使わない方法の両方）と、コピー後の書き換え作業。**このプロジェクトでは実施済み**で、次に別のプロジェクトを作るときに使う |
| [`gitの操作ルール.md`](gitの操作ルール.md) | 変更を Git に反映する手順（ブランチ → PR → CI → マージ → 後片付け）と、ドキュメントだけの変更で CI を止める方法 |
| [`ローカル環境での実行手順.md`](ローカル環境での実行手順.md) | 初回セットアップ・毎日の起動と終了・`/login` の見方・よくあるエラー（ポート競合等）の対処 |

**ここに足すとよいもの**（プロジェクトで必要になった時点で作る）:

- デバッグ手順（IDE のデバッグ構成の使い方）
- 本番リリース手順（全体の流れ。個々の手順は `docs/specs/99_infra/` へ）
- DB 定義を変更したい場合の流れ
