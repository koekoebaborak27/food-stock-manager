# 通知の設定画面

ヘッダーのメニューから開く（[00_画面共通.md 1](../00_共通/00_画面共通.md#1-画面の枠)）。下部タブと右下の追加ボタンは出さない。

## 1. 表示・操作

| 項目 | 内容 |
| --- | --- |
| 通知を受け取るトグル | 利用者ごとの設定。初期値オフ。オンにする操作の流れは [00_期限通知共通.md 2](00_期限通知共通.md#2-通知を有効にする操作の流れ) |
| 通知時刻の選択 | 世帯共通の設定。時（0〜23）と分（0・15・30・45）を選ぶ 2 つの選択式。初期値 8:00 |
| 案内文 | 通知時刻の選択の下に「ご家族の誰かが変更すると、全員の通知時刻が変わります。」と 1 行添える |

- どちらの項目も保存ボタンを置かず、操作した時点で保存する（[00_期限通知共通.md 4](00_期限通知共通.md#4-通知を無効にする操作)、[5](00_期限通知共通.md#5-通知時刻の変更)）。

## 2. 画面を開いたときの読み込み

- `GET /api/push-subscriptions/me` の `subscribed` をトグルの初期値にする。
- `GET /api/notification-settings` の `hour` `minute` を選択式の初期値にする。
- 読み込みに失敗した場合は、[00_画面共通.md 7](../00_共通/00_画面共通.md#7-読み込み中空失敗の表示)の「失敗」表示（中央にエラーの文言と「もう一度読み込む」）に従う。

## 3. トグルを操作したときの表示

| 操作 | 成功したときの表示 | 失敗・中断したときの表示 |
| --- | --- | --- |
| オンにする | 画面下部の帯「保存しました」 | [00_期限通知共通.md 3](00_期限通知共通.md#3-通知を有効にできないときの表示)の案内。トグルはオフに戻す |
| オフにする | 画面下部の帯「保存しました」 | 画面下部の帯「うまくいきませんでした。もう一度お試しください。」トグルはオンに戻す |

## 4. 通知時刻を変えたときの表示

- 保存できたら画面下部の帯「保存しました」を出す。
- 保存に失敗したら画面下部の帯「うまくいきませんでした。もう一度お試しください。」を出し、選択を保存前の値に戻す。
