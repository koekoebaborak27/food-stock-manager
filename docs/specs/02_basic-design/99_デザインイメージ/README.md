# 99_デザインイメージ — 配色と部品の参照元

先行して作った別アプリ「家族de TODO」の画面イメージ。**このアプリの配色・カード・タグ・ボタンの形を決めた根拠**として置いている。

用途はあくまで見た目の参照であり、**画面の構成と機能はこのアプリの各画面の設計書に従うこと。** ToDo アプリの画面をそのまま作らないこと。

## 引き継がないもの

- **一覧上部のフィルタ構成。** 参照元はセグメント 2 段・並び替えのセレクト 2 つ・カテゴリのピル列で 4 段あり、カードが画面の半分より下から始まっている。このアプリでは「保存区分タブ 1 段」＋「期限が近い食品があるときだけ出る 1 行」の 2 段に圧縮すること（[画面共通](../00_共通/00_画面共通.md)）。
- **優先度・繰り返し・担当者・コメント。** ToDo アプリ固有の機能であり、このアプリには無い。
- **画面上の文言。** ToDo アプリのものをそのまま使わない。文言は [共通文言](../00_共通/03_共通文言.md) と各画面の設計書に従うこと。

## 色について

参照元の画像から目視で拾った色味は、要件の [デザインの方針](../../01_requirements/00_共通/01_プロダクト共通.md) に文章で残してある。**実際に使う色の値は `DESIGN.md` とデザイントークンが正本**であり、この画像から色を直接スポイトして JSX に書かないこと。
