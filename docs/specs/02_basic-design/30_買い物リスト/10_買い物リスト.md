# 買い物リスト画面

下部タブから開く画面。買う商品を未購入と購入済みに分けて確認・操作する（[00_画面共通.md 1](../00_共通/00_画面共通.md#1-画面の枠)）。

## 1. 画面構成

上から次の順に並べる。

| 位置 | 内容 |
| --- | --- |
| ヘッダー | 見出し「買い物リスト」、メニュー（三本線） |
| 未購入一覧 | 未購入の商品。作成日時の古い順 |
| 購入済みの見出し | 購入済みがあるときだけ表示。件数と開閉する操作 |
| 購入済み一覧 | 見出しを開いたときだけ表示。作成日時の古い順 |

右下の追加ボタン（FAB）を置く。押すと画面を移さず、商品を直接入力するシートを出す。

- 購入済みは画面を開いた直後は閉じ、「購入済み（N件）」と表示する。同じ画面で再読込しても開閉状態を保つ。未購入が 0 件で購入済みだけある場合は「未購入の商品はありません。」を未購入欄に出す。
- アイコンには「『〇〇』を購入済みにする」「『〇〇』を未購入に戻す」「『〇〇』を削除する」の読み上げ名を付ける。開閉操作では開いているかどうかも読み上げられるようにする。

## 2. 商品の行

| 位置 | 内容 |
| --- | --- |
| 左端 | 購入状態を表すチェック。未購入は空、購入済みはチェック済み |
| 中央 | 商品名 |
| 右端 | ゴミ箱アイコン |

- チェックとゴミ箱は押し間違えないよう両端に離して置く。ゴミ箱は赤で塗らない（[画面遷移図 5](../画面遷移図.md#5-削除と消費済の違い)）。
- 商品名を押す操作や詳細画面は設けない。数量・単位・メモ・追加者も表示しない。
- 購入済みの行も同じ配置とし、チェックとゴミ箱を操作できる。

## 3. 商品を直接入力して追加する

FAB を押すと、見出し「商品を追加」のシートを出す。入力欄「商品名」と「追加する」ボタン、最下部に「キャンセル」を置く。

- 「追加する」を押すと `POST /api/shopping-items` を呼ぶ。追加できたらシートを閉じ、未購入一覧を読み直し、画面下部の帯で「買い物リストに追加しました」と伝える。
- 商品名は前後の空白を除いて 1〜30 文字とする。未入力・上限超過の文言は下記 7 節に従う。
- 同名の未購入商品があるなら、入力欄の直下に「この商品はすでにリストにあります。」と出す。入力欄は閉じず、内容を直せるようにする。
- 入力チェックと通信できないときの扱いは [00_画面共通.md 8](../00_共通/00_画面共通.md#8-入力チェックの出し方)、[00_画面共通.md 10](../00_共通/00_画面共通.md#10-通信できないとき) に従う。

## 4. 購入状態を変える

- 購入済みのチェックを外すと、`PATCH /api/shopping-items/{id}/purchased` に `isPurchased: false` を送る。成功したら未購入一覧と購入済みの件数を読み直す。常備食は変更しない。
- 未購入のチェックを入れると、画面を移さず下から購入確認シートを出す。確認するまで購入済みに変更しない。

### 4.1 購入確認シート

見出しは「「〇〇」を購入しましたか」とする。〇〇には商品名を入れる。

| 順番 | 内容 |
| --- | --- |
| 1 | 「常備食へ戻す」の選択。初期値は戻す |
| 2 | 戻すと選んだときだけ保存区分「冷蔵 / 冷凍 / 常温」を横に並べる |
| 3 | 「購入済みにする」ボタン |
| 4 | 「キャンセル」 |

- 保存区分は元の常備食が未削除なら消費済でもその保存区分を使い、削除済みか元の常備食がないなら「冷蔵」を初期選択にする。
- 保存区分の下に「元の常備食と同じ保存区分なら残数を1増やし、異なる場合は新しく登録します。元の常備食がない場合や消費済みの場合も新しく登録します。」と表示する。どの保存区分も選べるようにする。
- 「購入済みにする」を押すと `PATCH /api/shopping-items/{id}/purchased` を呼ぶ。常備食へ戻す選択と保存区分も送る。成功したらシートを閉じ、一覧を読み直す。
- 購入済みにするだけを選んだ場合、常備食へは何も登録しない。常備食へ戻す場合の登録内容は [00_買い物リスト共通.md 3](00_買い物リスト共通.md#3-購入状態と常備食への登録) に従う。
- 戻さない選択の表示名は「常備食へ戻さない」とする。期限・残数の入力欄は置かない。「キャンセル」やシートの外側を押した場合は何も変更しない。
- 送信中は実行ボタンと対象行のチェック・削除操作を無効にする。成功したら「購入済みにしました」、常備食にも反映した場合は「購入済みにして、常備食に反映しました」と帯に出す。
- 未購入に戻す場合は「常備食の残数は変わりません。」と購入済み一覧に補足する。成功時は「未購入に戻しました」と帯に出す。

## 5. 削除

- ゴミ箱を押すと、共通文言の確認ダイアログを出す（[03_共通文言.md 6](../00_共通/03_共通文言.md#6-確認ダイアログ)）。確認後に `DELETE /api/shopping-items/{id}` を呼ぶ。
- 削除できたら一覧から外し、画面下部の帯に共通文言の削除完了通知と「元に戻す」を 5 秒出す。「元に戻す」を押すと `POST /api/shopping-items/restore` を呼ぶ。
- 購入済みが 1 件以上あるときだけ、購入済みの見出しに「購入済みを削除する」を置く。押すと見出し「購入済みの商品をすべて削除しますか」、本文「購入済みの商品が買い物リストから消えます。常備食には何もしません。」、ボタン「キャンセル / 削除する」の確認ダイアログを出す。
- 一括削除後は、削除した商品をすべて対象に「元に戻す」を 5 秒出す。
- 一括削除の確認本文には「対象：N件」を添える。確認を開いた時点の対象 ID と `updatedAt` を送信し、確認後に増えた商品は削除しない。成功時の帯は「購入済みの商品をN件削除しました」とする。
- 復元時は削除成功の応答で得た ID と `updatedAt` を送る。成功したら一覧を再読込し「元に戻しました」と表示する。

## 6. 読み込み中・空・失敗・再読込

- 読み込み中・失敗・通信できないときは [00_画面共通.md 7](../00_共通/00_画面共通.md#7-読み込み中空失敗の表示)、[00_画面共通.md 10](../00_共通/00_画面共通.md#10-通信できないとき) に従う。
- 商品が 1 件もないときは「買うものはまだありません。」と「商品を追加する」ボタンを出す。ボタンは FAB と同じ直接入力シートを開く。
- 画面を開いたとき、引き下げ操作をしたとき、自分が追加・変更・削除した直後に一覧を読み直す。開いたまま自動更新はしない。

## 7. 入力チェックと失敗時の文言

| `code` | 表示する文言 | 表示と次の操作 |
| --- | --- | --- |
| `SHOPPING_ITEM_NAME_REQUIRED` | 入力してください | 商品名の直下。入力は保持する |
| `SHOPPING_ITEM_NAME_TOO_LONG` | 30文字以内で入力してください | 商品名の直下。入力は保持する |
| `SHOPPING_ITEM_ALREADY_EXISTS` | この商品はすでにリストにあります。 | 直接入力では商品名の直下。それ以外では画面下部の帯。変更せず一覧を再読込する |
| `SHOPPING_ITEM_NOT_FOUND` / `SOURCE_STOCK_NOT_FOUND` | 共通文言の `NOT_FOUND` と同じ | シートを閉じて操作元の一覧を再読込する |
| `SHOPPING_ITEM_UPDATE_CONFLICT` | 共通文言「更新の競合」と同じ | 「読み込み直す」のダイアログ。購入確認を閉じて再読込し、自動で再送しない |
| `SOURCE_STOCK_QUANTITY_LIMIT` | 元の常備食は残数が99のため追加できません。「常備食へ戻さない」を選ぶか、常備食の残数を確認してください。 | 購入確認シート内。入力を保持し、戻さない選択を可能にする |
| `INVALID_PURCHASE_UPDATE` / `VALIDATION_ERROR` | 入力内容を確認できませんでした。画面を読み込み直して、もう一度お試しください。 | 画面下部の帯。再読込は利用者の操作で行う |

通信・認証・未知の失敗は [共通文言](../00_共通/03_共通文言.md) に従う。通信失敗時は成功扱いにせず入力を保持し、再試行前に一覧を読み直して処理済みか確かめる。再読込だけが失敗した場合は書き込みを再送しない。

常備食リスト・詳細・消費済リストからの追加も本節の文言を使う。在庫切れシートで重複した場合は、消費済への変更を反映したうえで「この商品はすでにリストにあります。」と帯に出す。

## 8. DB への影響

| 操作 | `ShoppingItem` | `Stock` |
| --- | --- | --- |
| 一覧・シートを開く・キャンセル | 変更なし | 変更なし |
| 直接入力・常備食から追加 | 未購入の行を作成 | 変更なし。在庫切れシートからの操作だけ消費済処理を伴う |
| 購入済みへ変更 | `isPurchased = true` | 戻す選択の場合だけ共通仕様に従い加算または新規作成 |
| 未購入へ変更 | `isPurchased = false` | 変更なし |
| 1 件・一括削除 | `deletedAt` を設定 | 変更なし |
| 元に戻す | `deletedAt = null` | 変更なし |

更新時は共通仕様に従い `updatedAt`・`updatedById` を更新する。競合・入力不正では一部だけの変更を残さない。
