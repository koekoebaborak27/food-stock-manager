# 常備食管理共通

この機能のどの画面にも関わる決まり。個々の画面は [README.md の索引](README.md) から見ること。

## 1. 権限

世帯に所属する利用者は全員、常備食の登録・編集・削除・残数の増減・消費済リストの閲覧と再登録ができる。作成者以外による編集・削除も妨げない（[要件定義 5. 権限](../../01_requirements/20_常備食管理/01_常備食管理.md#5-権限)）。10_認証と家族グループのような管理者限定の操作はない。

## 2. 保存区分・単位の内部値

データベースでは列挙型で持ち、画面には要件定義の表示文字を出す（[00_画面共通.md 3](../00_共通/00_画面共通.md#3-タグの表示)）。

### 2.1 保存区分（`StorageType`）

| 内部値 | 表示 |
| --- | --- |
| `REFRIGERATED` | 冷蔵 |
| `FROZEN` | 冷凍 |
| `ROOM_TEMPERATURE` | 常温 |

- 未選択のまま保存しようとした場合の初期値は `REFRIGERATED`（冷蔵）とする（[要件定義 6](../../01_requirements/20_常備食管理/01_常備食管理.md#6-例外時の扱い)）。登録・編集画面では常に「冷蔵」を選択済みにしておくため、通常は未選択の状態自体が起きない。

### 2.2 単位（`UnitType`）

| 内部値 | 表示 |
| --- | --- |
| `PIECE` | 個 |
| `BAG` | 袋 |
| `PACK` | パック |
| `SERVING` | 食分 |
| `BOTTLE` | 本 |
| `GOTO` | ごと |

- 未選択（`null`）を許す。未選択のときは残数の数字だけを表示する（[00_画面共通.md 4](../00_共通/00_画面共通.md#4-数と日付の書き方)）。

## 3. 文字数の上限

[00_共通の基本設計を決めたときの保留事項](../../../todo/history/2026-09-05_共通の基本設計.md#2026-09-05-保留にしたこと)で「各機能の設計で決める」としていた値。文言の形は [03_共通文言.md 4](../00_共通/03_共通文言.md#4-入力チェック) のとおり。

| 項目 | 上限 | 上限超過時の文言 |
| --- | --- | --- |
| 食品名 | 30文字 | 30文字以内で入力してください |
| メモ | 200文字 | 200文字以内で入力してください |

## 4. 残数の増減と消費済

常備食リストのカード・詳細画面のどちらでも同じ挙動とする（[要件定義 4.7](../../01_requirements/20_常備食管理/01_常備食管理.md#47-残数の増減と消費済)）。

- 「+」「−」ボタンを押すたびに1ずつ増減する。増減は [01_データベース共通.md 5](../00_共通/01_データベース共通.md#5-更新の競合) のとおり差分としてデータベース側で計算し、更新の競合の確認をしない。
- 残数を0未満にしない。0のときは「−」を押せない見た目にする。
- 残数を0にした直後だけ、[00_画面共通.md 6.3](../00_共通/00_画面共通.md#63-下から出るシート) の下から出るシートを表示する。見出しは「在庫がなくなりました」とする。

| 選択肢 | 動作 |
| --- | --- |
| 消費済にする | 消費済にする。一覧から外れ、消費済リストに出る |
| 消費済にして、買い物リストに追加する | 消費済にしたうえで、食品名を商品名として買い物リストへ追加する |
| そのままにする | 何もしない。残数0のまま一覧に残す |

- シートの一番下に「キャンセル」を置き、「そのままにする」と同じ扱いとする。
- 「そのままにする」を選んだ食品は、一覧のカードに「在庫切れ」のタグを付ける。
- 消費済にした食品は `consumedAt` に日時を記録し、一覧の問い合わせから除く（[01_データベース.md](01_データベース.md)）。データは削除しない。

## 5. 削除と元に戻す

一覧・詳細のどちらからも削除できる（[要件定義 4.8](../../01_requirements/20_常備食管理/01_常備食管理.md#48-削除)）。確認ダイアログと文言は共通（[00_画面共通.md 6.2](../00_共通/00_画面共通.md#62-確認ダイアログ)、[03_共通文言.md 6](../00_共通/03_共通文言.md#6-確認ダイアログ)）。

- 削除は [01_データベース共通.md 6](../00_共通/01_データベース共通.md#6-消し方) の「取り消す（削除）」。`deletedAt` を立て、一覧にも消費済リストにも出さない。
- 削除直後は画面下部の帯に「元に戻す」を5秒表示する（[03_共通文言.md 7](../00_共通/03_共通文言.md#7-うまくいったときの帯)）。押すと `deletedAt` を空に戻す。5秒を過ぎたら操作できない。
