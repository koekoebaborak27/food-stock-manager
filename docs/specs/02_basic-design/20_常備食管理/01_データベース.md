# データベース

列の共通ルール（`id` `createdAt` `updatedAt`、家族グループでの切り分け、作った人・更新した人、更新の競合、消し方、個人情報の消し方）は [01_データベース共通.md](../00_共通/01_データベース共通.md) のとおり。ここでは `Stock` の列を定める。

## 1. Stock

| 列 | 型 | 決まり |
| --- | --- | --- |
| `householdId` | UUID | 属する家族グループ。外部キー、索引あり |
| `name` | 文字列（30文字以内） | 食品名。必須 |
| `storageType` | 列挙型 `StorageType`（[00_常備食管理共通.md 2.1](00_常備食管理共通.md#21-保存区分storagetype)） | 必須。既定値 `REFRIGERATED` |
| `quantity` | 整数 | 残数。0以上99以下。既定値 1 |
| `unit` | 列挙型 `UnitType`、null許容（[00_常備食管理共通.md 2.2](00_常備食管理共通.md#22-単位unittype)） | 未選択でよい |
| `expiresOn` | 日付、null許容（時刻を持たない） | 未設定でよい |
| `isHomemade` | 真偽値 | 作り置きかどうか。既定値 `false` |
| `memo` | 文字列（200文字以内）、null許容 | 自由記述 |
| `consumedAt` | 日時、null許容 | 消費済にした日時。`null` は消費済でないことを表す |
| `createdById` | UUID、null許容 | 登録した利用者（[01_データベース共通.md 4](../00_共通/01_データベース共通.md#4-作った人更新した人)） |
| `updatedById` | UUID、null許容 | 最後に更新した利用者 |
| `deletedAt` | 日時、null許容 | 削除した日時（[01_データベース共通.md 6](../00_共通/01_データベース共通.md#6-消し方)） |

- 一覧の問い合わせは常に `householdId` の条件に加え、`deletedAt IS NULL` を付ける。常備食リストはさらに `consumedAt IS NULL`、消費済リストは `consumedAt IS NOT NULL` を付ける。
- 同じ `householdId` に同じ `name` があっても保存できる（一意制約を付けない）。登録時の重複チェックは、保存直前に同じ `householdId`・`deletedAt IS NULL`・`consumedAt IS NULL` の範囲で `name` が一致する行の有無を調べるだけとする。
- 既定の並び順は `expiresOn` の昇順（`null` は最後）。「追加順（新しい順）」は `createdAt` の降順、「名前順」は `name` の昇順。並び替えの索引は `(householdId, deletedAt, consumedAt, expiresOn)` に付ける。
- 消費済リストの並び順は `consumedAt` の降順。
