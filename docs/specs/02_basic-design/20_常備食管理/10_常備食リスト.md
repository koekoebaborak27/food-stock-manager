# 常備食リスト画面

アプリの入口となる画面。下部タブから開く（[00_画面共通.md 1](../00_共通/00_画面共通.md#1-画面の枠)）。

## 1. 画面構成

上から次の順に並べる。フィルタを画面の上半分に積み上げない。

| 位置 | 内容 |
| --- | --- |
| ヘッダー | 世帯名、検索アイコン、並び替えアイコン、メニュー（三本線） |
| 保存区分タブ | 「すべて / 冷蔵 / 冷凍 / 常温」を1段で常に表示 |
| 期限注意バー | 期限切れ・今日・明日が期限の食品があるときだけ1行 |
| カード一覧 | 常備食のカード |

右下に追加ボタン（FAB）を置く。押すと[常備食の登録・編集画面](11_常備食の登録編集.md)を登録として開く（[00_画面共通.md 2](../00_共通/00_画面共通.md#2-右下の追加ボタンfab)）。

## 2. 保存区分タブ

- 選択中のタブで一覧を絞り込む（`GET /api/stocks?storageType=...`）。
- タブを切り替えても検索文字列・並び順は保持する。

## 3. 期限注意バー

- 表示条件: 選択中のタブの中に、期限切れ・今日・明日が期限の食品が1件以上ある（[00_画面共通.md 3.2](../00_共通/00_画面共通.md#32-期限の状態)）。
- 文言: 「期限が近い食品がN件あります」（Nは件数）。
- 押すと `urgentOnly=true` で絞り込み、バーの代わりに「期限が近い食品だけ表示中」のチップと解除ボタンを出す。解除するとタブ本来の一覧に戻る。
- プッシュ通知から開いたときは、この絞り込み済みの状態で開く（[画面遷移図 3](../画面遷移図.md#3-図01-全体の画面遷移)）。

## 4. 検索

- 検索アイコンを押すと入力欄が現れる。閉じると入力欄と絞り込みを消す。
- 食品名の部分一致で絞り込む（`keyword`）。メモは対象にしない。
- 選択中の保存区分タブの中で検索する。

## 5. 並び替え

- 並び替えアイコンを押すと、[00_画面共通.md 6.3](../00_共通/00_画面共通.md#63-下から出るシート) の形式でシートを出す。
- 選択肢: 「期限が近い順」（既定）「追加順（新しい順）」「名前順」「キャンセル」。
- 選んだ並び順はこの画面を開いている間だけ保持する（次回起動時は既定に戻る）。

## 6. カード

| 表示項目 | 内容 |
| --- | --- |
| 食品名 | |
| 保存区分 | タグ（[00_画面共通.md 3.1](../00_共通/00_画面共通.md#31-保存区分)） |
| 残数と単位 | [00_画面共通.md 4](../00_共通/00_画面共通.md#4-数と日付の書き方) |
| 期限の状態 | タグ（[00_画面共通.md 3.2](../00_共通/00_画面共通.md#32-期限の状態)）。未設定なら出さない |
| 作り置き | タグ（[00_画面共通.md 3.3](../00_共通/00_画面共通.md#33-作り置き)）。作り置きの食品だけ |
| 在庫切れ | タグ。残数0で「そのままにする」を選んだ食品だけ（[00_常備食管理共通.md 4](00_常備食管理共通.md#4-残数の増減と消費済)） |

配置と操作:

- 食品名と同じ行の右端に、カート・ゴミ箱のアイコンをこの順で並べる。
- 残数の増減ボタン（−／+）はカードの下段に置き、カート・ゴミ箱から離す。
- カート: 押すと画面を移さず買い物リストへ追加し、下部の帯で「買い物リストに追加しました」と伝える（30_買い物リスト の処理を呼ぶ）。常備食はそのまま残す。
- ゴミ箱: 赤で塗らない。押すと確認ダイアログを出す（[03_共通文言.md 6](../00_共通/03_共通文言.md#6-確認ダイアログ)）。削除後は帯に「元に戻す」を5秒表示する。
- 増減ボタン: 押すと `PATCH /api/stocks/{id}/quantity` を呼ぶ。0になった直後だけ消費済のシートを出す（[00_常備食管理共通.md 4](00_常備食管理共通.md#4-残数の増減と消費済)）。
- カード本体を押すと[常備食の詳細画面](12_常備食の詳細.md)へ進む。

## 7. 読み込み中・空・失敗

[00_画面共通.md 7](../00_共通/00_画面共通.md#7-読み込み中空失敗の表示) のとおり。0件のときの文言は [03_共通文言.md 8](../00_共通/03_共通文言.md#8-何もないときの表示) の「常備食リスト」の行を使う。検索・絞り込みの結果が0件のときは「見つかりませんでした。」と絞り込みを外すボタンを出す。

## 8. 再読込

引き下げ操作、または画面を開いたときに再読込する。開いたまま自動更新はしない（[00_画面共通.md 7](../00_共通/00_画面共通.md#7-読み込み中空失敗の表示)、[画面遷移図 3](../画面遷移図.md#3-図01-全体の画面遷移)）。
