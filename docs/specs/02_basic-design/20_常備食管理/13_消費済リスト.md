# 消費済リスト画面

下部タブから開く（[00_画面共通.md 1](../00_共通/00_画面共通.md#1-画面の枠)）。追加ボタン（FAB）は置かない（[00_画面共通.md 2](../00_共通/00_画面共通.md#2-右下の追加ボタンfab)）。

## 1. 表示項目

消費済にした日付の新しい順に並べる。

| 項目 | 内容 |
| --- | --- |
| 食品名 | |
| 保存区分 | タグ |
| 単位 | 未選択なら出さない |
| 消費済にした日付 | [00_画面共通.md 4](../00_共通/00_画面共通.md#4-数と日付の書き方) |

## 2. 操作

1件ずつ、次の2つの操作を並べて置く。削除の操作は置かない。

| 操作 | 内容 |
| --- | --- |
| 常備食へ戻す | `POST /api/stocks/{id}/re-register` で食品名・保存区分・単位を引き継いだ新しい食品を作り、[常備食の登録・編集画面](11_常備食の登録編集.md)を編集として開く |
| 買い物リストへ追加する | 食品名を商品名として買い物リストへ追加し、元の常備食（この `Stock` の `id`）を記録する（30_買い物リスト の設計）。画面は移らず、下部の帯で伝える。消費済リストからは外さない |

## 3. 読み込み中・空・失敗

[00_画面共通.md 7](../00_共通/00_画面共通.md#7-読み込み中空失敗の表示) のとおり。0件のときの文言は [03_共通文言.md 8](../00_共通/03_共通文言.md#8-何もないときの表示) の「消費済リスト」の行を使う。
