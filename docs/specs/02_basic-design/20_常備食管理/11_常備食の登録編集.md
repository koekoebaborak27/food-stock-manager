# 常備食の登録・編集画面

登録・編集で同じ画面を使う（[要件定義 4.5](../../01_requirements/20_常備食管理/01_常備食管理.md#45-登録と編集)）。子画面のため下部タブは出さず、ヘッダー左に戻るボタンを置く（[00_画面共通.md 1](../00_共通/00_画面共通.md#1-画面の枠)）。

## 1. 入力項目

| 項目 | 入力方法 | 必須 | 初期値 |
| --- | --- | --- | --- |
| 食品名 | 1行テキスト、30文字以内 | 必須 | 空（編集時は現在値） |
| 保存区分 | 「冷蔵・冷凍・常温」から1つ選ぶ | 必須 | 冷蔵 |
| 残数 | 数字入力、0〜99 | 必須 | 1 |
| 単位 | 「個・袋・パック・食分・本・ごと」または未選択 | 任意 | 未選択 |
| 期限 | カレンダーから日付を選ぶ | 任意 | 未設定 |
| 作り置き | チェック | 任意 | オフ |
| メモ | 複数行テキスト、200文字以内 | 任意 | 空 |

## 2. 入力チェック

保存を押した時点でまとめて調べる（[00_画面共通.md 8](../00_共通/00_画面共通.md#8-入力チェックの出し方)）。文言は [03_共通文言.md 4](../00_共通/03_共通文言.md#4-入力チェック) の形を使う。

| 項目 | 条件 | 文言 |
| --- | --- | --- |
| 食品名 | 未入力 | 入力してください |
| 食品名 | 31文字以上 | 30文字以内で入力してください |
| 残数 | 未入力、または数字でない | 数字で入力してください |
| 残数 | 0未満、または100以上 | 0以上99以下で入力してください |
| メモ | 201文字以上 | 200文字以内で入力してください |

- 保存区分は常に選択済みの状態で画面を開くため、未選択のまま保存されることはない。バックエンド側の入力チェックは[要件定義 6](../../01_requirements/20_常備食管理/01_常備食管理.md#6-例外時の扱い)のとおり必須のまま持つ。

## 3. 保存

- 保存すると[常備食リスト画面](10_常備食リスト.md)へ戻り、画面下部の帯で結果を伝える（[03_共通文言.md 7](../00_共通/03_共通文言.md#7-うまくいったときの帯)）。
- 登録時、同じ食品名がすでにある場合（応答の `duplicateName: true`）は、帯の文言を「保存しました（同じ名前の食品がすでにあります）」とする。ない場合は「保存しました」とする。登録は妨げず、同名の食品をまとめない。
- 保存中はボタンを押せなくする（[00_画面共通.md 8](../00_共通/00_画面共通.md#8-入力チェックの出し方)）。
- 編集時、他の利用者が先に更新していた場合（`STOCK_UPDATE_CONFLICT`）は保存せず、[03_共通文言.md 5](../00_共通/03_共通文言.md#5-更新の競合) のダイアログを出し、最新の内容を読み直す。
- 入力を取りやめると、確認なく元の画面（[常備食リスト画面](10_常備食リスト.md)、または編集の場合は[常備食の詳細画面](12_常備食の詳細.md)）へ戻る。

## 4. 消費済リストからの再登録

[消費済リスト画面](13_消費済リスト.md)の「常備食へ戻す」から開いたときは、`POST /api/stocks/{id}/re-register` ですでに作成された食品（食品名・保存区分・単位を引き継ぎ、残数1・期限未設定）をこの画面で編集する状態として開く。保存すると[常備食リスト画面](10_常備食リスト.md)へ戻る。
