# 常備食の詳細画面

常備食リストのカードを押して開く。子画面のため下部タブは出さない（[00_画面共通.md 1](../00_共通/00_画面共通.md#1-画面の枠)）。

## 1. 表示項目

| 項目 | 内容 |
| --- | --- |
| 食品名 | |
| 保存区分 | タグ |
| 残数と単位 | 増減ボタン付き |
| 期限 | [00_画面共通.md 4](../00_共通/00_画面共通.md#4-数と日付の書き方)の「詳細・確認文」の書き方（例: 2026年9月5日） |
| 作り置き | タグ。作り置きの食品だけ |
| メモ | |
| 作成者・作成日時 | 画面下部。退会したメンバーの扱いは [00_画面共通.md 5](../00_共通/00_画面共通.md#5-人の名前の表示) |
| 更新者・更新日時 | 画面下部 |

## 2. 操作

| 操作 | 内容 |
| --- | --- |
| 残数の増減 | [00_常備食管理共通.md 4](00_常備食管理共通.md#4-残数の増減と消費済)のとおり。0になった直後は消費済のシートを出す |
| 編集 | [常備食の登録・編集画面](11_常備食の登録編集.md)を編集として開く |
| 削除 | 確認ダイアログの後に削除し、[常備食リスト画面](10_常備食リスト.md)へ戻る。戻った先の帯に「元に戻す」を5秒表示する |
| 買い物リストへ追加 | 画面を移さず追加し、下部の帯で伝える。常備食はそのまま残す |

## 3. 表示中の食品が消えていた場合

この画面を表示中に、他の利用者がその食品を削除または消費済にしていた場合（`STOCK_NOT_FOUND`）、操作をさせず[常備食リスト画面](10_常備食リスト.md)へ戻し、[03_共通文言.md 3](../00_共通/03_共通文言.md#3-ログインと権限)の「対象が見つからない」の文言を帯で出す（[要件定義 6](../../01_requirements/20_常備食管理/01_常備食管理.md#6-例外時の扱い)）。
