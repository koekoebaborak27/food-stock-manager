# 共通文言

**画面に出す文字列の正本。** 機能をまたいで同じ場面で使うものだけをここに置く。ある機能でしか使わない文言は、その機能の設計書に書くこと。

単体テスト仕様書はここから文字列をそのまま写すこと。文言を変えるときは、まずこのファイルを直すこと。

## 1. 書き方の決まり

- 利用者に「世帯」と書かないこと。「家族グループ」と書くこと。
- 「エラー」「バリデーション」「トークン」などの言葉を画面に出さないこと。
- 何が起きたかと、次に何をすればよいかを 1 文ずつで書くこと。3 文以上にしないこと。
- 文末は「です・ます」で揃えること。感嘆符を使わないこと。
- 利用者の入力を文中に入れるときは、かぎかっこで囲むこと。例: 「にんじん」を削除しますか

## 2. 通信と読み込みの失敗

| 場面 | 出し方 | 文言 |
| --- | --- | --- |
| 通信できない | 画面上部の消えない帯 | インターネットへの接続が必要です |
| 一覧の読み込みに失敗した | 一覧の場所に中央寄せ | 読み込めませんでした。通信の状態を確かめて、もう一度お試しください。 |
| 上のボタン | ボタン | もう一度読み込む |
| 保存・追加・削除に失敗した | 画面下部の帯 | うまくいきませんでした。もう一度お試しください。 |
| 原因の分からない失敗（`SERVER_ERROR`） | 画面下部の帯 | うまくいきませんでした。しばらく待ってからお試しください。 |
| 呼びすぎ（`TOO_MANY_REQUESTS`） | 画面下部の帯 | 操作が続いています。少し待ってからお試しください。 |

## 3. ログインと権限

| 場面 | `code` | 出し方 | 文言 |
| --- | --- | --- | --- |
| セッションが切れた | `UNAUTHENTICATED` | ログイン画面へ移し、画面上部に帯 | ログインの有効期限が切れました。もう一度ログインしてください。 |
| 権限がない | `FORBIDDEN` | 画面下部の帯 | この操作はご家族の管理者だけができます。 |
| どの家族グループにも属していない | `NO_HOUSEHOLD` | 家族グループの選択画面へ移す | （帯を出さないこと） |
| 対象が見つからない | `NOT_FOUND` | 一覧へ戻し、画面下部の帯 | このデータは見つかりませんでした。ご家族の誰かが削除した可能性があります。 |

## 4. 入力チェック

入力欄のすぐ下に赤い文字で出すこと。

| 場面 | 文言 |
| --- | --- |
| 必須の項目が空 | 入力してください |
| 文字数が上限を超えた | ○文字以内で入力してください |
| 数字でない | 数字で入力してください |
| 数の範囲外 | ○以上○以下で入力してください |
| 日付の形が正しくない | 日付を選んでください |

- ○には、その項目の実際の上限・下限を入れること。値は各機能の設計書に書く。
- 項目名を文言に含めないこと。入力欄のすぐ下に出すため、どの項目かは位置で分かる。

## 5. 更新の競合

| 場面 | 出し方 | 文言 |
| --- | --- | --- |
| 保存しようとしたら先に更新されていた | ダイアログ（ボタンは「読み込み直す」のみ） | ご家族の誰かが先に変更しました。最新の内容を読み込みます。 |

- このダイアログには「キャンセル」を置かないこと。閉じたら必ず読み直すこと。

## 6. 確認ダイアログ

〇〇には食品名・商品名・メンバーの名前を入れること。

| 対象 | 見出し | 本文 | ボタン |
| --- | --- | --- | --- |
| 常備食 | 「〇〇」を削除しますか | 一覧から消えます。消費済リストにも残りません。食べ終えた場合は、削除ではなく残数を0にしてください。 | キャンセル / 削除する |
| 買い物リストの商品 | 「〇〇」を削除しますか | 買い物リストから消えます。常備食には何もしません。 | キャンセル / 削除する |

- 上の 2 つは [画面遷移図](../画面遷移図.md) と同じ文言とすること。片方だけ直さないこと。
- 除名・家族グループの削除・脱退・退会の確認文は、10_認証と家族グループ の設計書に書くこと。

## 7. うまくいったときの帯

| 場面 | 文言 |
| --- | --- |
| 削除した（取り消しあり） | 「〇〇」を削除しました ＋ 元に戻す |
| 買い物リストへ追加した | 買い物リストに追加しました |
| 保存した | 保存しました |

- 「元に戻す」は帯の右端に置き、5 秒で消えること。
- 登録・編集の保存のように画面が移る操作では、移った先で帯を出すこと。

## 8. 何もないときの表示

| 画面 | 文言 | ボタン |
| --- | --- | --- |
| 常備食リスト | まだ登録がありません。右下のボタンから食品を追加してください。 | 食品を追加する |
| 買い物リスト | 買うものはまだありません。 | 商品を追加する |
| 消費済リスト | 食べ終えた食品がここに並びます。 | （ボタンを出さないこと） |

- 絞り込みや検索の結果が 0 件のときは、上の文言を出さないこと。代わりに「見つかりませんでした。」と出し、絞り込みを外すボタンを添えること。
