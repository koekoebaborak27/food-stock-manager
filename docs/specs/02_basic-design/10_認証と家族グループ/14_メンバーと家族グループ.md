# メンバーと家族グループ画面

ヘッダーのメニューから開く（[00_画面共通.md 1](../00_共通/00_画面共通.md#1-画面の枠)）。

## 1. 表示・操作

| 項目 | 内容 |
| --- | --- |
| 表示 | 家族グループの名前、メンバー一覧（アイコン・表示名・管理者バッジ）（[02_API.md](02_API.md) の `GET /api/households/me`） |
| 一般メンバーに出す操作 | 自分の脱退ボタン、[招待コードの発行画面](15_招待コードの発行.md)への導線 |
| 管理者にだけ追加で出す操作 | 各メンバーの除名ボタン、家族グループの削除ボタン |

- 一般メンバーには除名ボタン・家族グループの削除ボタンを出さない（[00_画面共通.md 9](../00_共通/00_画面共通.md#9-権限による表示の差)）。管理者自身の行には除名ボタンを出さない。

## 2. 確認ダイアログ

[00_画面共通.md 6.2](../00_共通/00_画面共通.md#62-確認ダイアログ) の形式。ボタンは キャンセル / 実行。

| 対象 | 見出し | 本文 | 実行ボタン |
| --- | --- | --- | --- |
| 脱退 | 家族グループを脱退しますか | 常備食と買い物リストはご家族に残ります。もう一度参加するには招待コードが必要です。 | 脱退する |
| 除名 | 「〇〇」を除名しますか | 〇〇さんは家族グループから外れます。常備食と買い物リストは残ります。 | 除名する |
| 家族グループの削除 | 家族グループを削除しますか | 常備食・買い物リスト・消費済リストがすべて削除されます。元に戻せません。 | 削除する |

## 3. 脱退できないときの表示

管理者が脱退しようとしたが他のメンバーが残っている場合（`code: HOUSEHOLD_HAS_OTHER_MEMBERS`）、確認ダイアログの代わりに次を表示し、実行させない。

| 場面 | 出し方 | 文言 |
| --- | --- | --- |
| 管理者が他のメンバーを残したまま脱退しようとした | ダイアログ（ボタンは「閉じる」のみ） | 管理者は他のメンバーがいる間は脱退できません。先に家族グループを削除するか、他のメンバーを除名してください。 |
