# 招待コードの発行画面

[メンバーと家族グループ画面](14_メンバーと家族グループ.md)から開く。

## 1. 表示・操作

| 項目 | 内容 |
| --- | --- |
| 表示（自分が発行した有効なコードがある） | コード、有効期限（YYYY年M月D日 H:MM）、コピーボタン |
| 表示（コードがない・期限切れ） | 「招待コードを発行する」ボタンのみ（[02_API.md](02_API.md) の `POST /api/invitations`） |
| コピー成功時 | 画面下部の帯「コピーしました」（3秒で消える） |
