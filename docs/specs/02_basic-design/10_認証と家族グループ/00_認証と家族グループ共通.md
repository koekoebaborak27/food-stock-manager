## 1. 権限

[プロダクト共通要件の権限](../../01_requirements/00_共通/01_プロダクト共通.md#5-権限) のとおり。除名・家族グループの削除は管理者だけが呼べる。バックエンド側で必ず確かめ、フロントエンドはボタンを出さないだけで済ませない（[02_API共通.md](../00_共通/02_API共通.md)）。

## 2. ログイン状態の持ち方

[00_共通の基本設計を決めたときの保留事項](../../../todo/history/2026-09-05_共通の基本設計.md) で、この機能の設計で決めるとしていたセッションの具体的な決まり。

| 項目 | 決まり |
| --- | --- |
| Cookieの名前 | `session` |
| 属性 | `HttpOnly` `Secure` `SameSite=Lax` |
| 有効期限 | 発行から30日間 |
| 延長 | 有効期限内にアクセスがあれば、そのつど30日間へ延長する |
| 失効 | ログアウト・退会のときにCookieを消す。有効期限が切れた場合は次のAPI呼び出しで401（`UNAUTHENTICATED`）を返す |

- Cookieの中身は、利用者を一意に識別できる値（セッションID）だけとする。表示名やメールアドレスをCookieに入れない。
- セッションIDからログイン中の利用者・所属する家族グループ・役割を引けるようにする。実装方法は[詳細設計: セッション設計](../../03_detail-design/10_認証と家族グループ/01_セッション設計.md)のとおり。
