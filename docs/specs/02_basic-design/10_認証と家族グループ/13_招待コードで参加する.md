# 招待コードで参加する画面

## 1. 表示・操作

| 項目 | 内容 |
| --- | --- |
| 入力欄 | 招待コード（1行テキスト、必須） |
| 保存ボタン | 「参加する」（[02_API.md](02_API.md) の `POST /api/invitations/redeem`） |
| 保存後 | 一般メンバーとして参加し、常備食リストへ遷移する |

- 招待コードの形式チェックはしない。存在するかどうかはサーバー側の判定に任せる。
- すでに家族グループに所属している状態でこの画面から参加しようとした場合（ブラウザの戻る操作等でこの画面に来たときを想定）は、参加する前に確認ダイアログ「今の家族グループを抜けて、新しい家族グループに参加しますか」（本文: 今の家族グループの常備食・買い物リストは今のご家族に残ります。／ボタン: キャンセル / 参加する）を表示する。

## 2. エラー文言

| 場面 | `code` | 出し方 | 文言 |
| --- | --- | --- | --- |
| 入力欄が空 | — | 入力欄の下 | 入力してください |
| コードが存在しない・すでに使われた | `INVITATION_NOT_FOUND` | 画面下部の帯 | 招待コードが見つかりません。コードを確かめてください。 |
| コードの有効期限が切れている | `INVITATION_EXPIRED` | 画面下部の帯 | この招待コードの有効期限が切れています。家族に再発行を頼んでください。 |
