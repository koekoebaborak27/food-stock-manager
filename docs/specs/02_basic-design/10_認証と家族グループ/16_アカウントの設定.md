# アカウントの設定画面

ヘッダーのメニューから開く（[00_画面共通.md 1](../00_共通/00_画面共通.md#1-画面の枠)）。

## 1. 表示・操作

| 項目 | 内容 |
| --- | --- |
| 表示 | アイコン、表示名（編集可）、メールアドレス（本人のみ表示） |
| 表示名の入力欄 | 1行テキスト、必須、20文字以内。入力チェックは [家族グループをつくる画面](12_家族グループをつくる.md) の名前と同じ文言 |
| 保存ボタン | 保存すると「保存しました」の帯を出す（[03_共通文言.md 7](../00_共通/03_共通文言.md#7-うまくいったときの帯)、[02_API.md](02_API.md) の `PATCH /api/users/me`） |
| 操作 | ログアウトボタン（`POST /api/auth/logout`）、退会ボタン（`DELETE /api/users/me`） |

## 2. 確認ダイアログ

| 対象 | 見出し | 本文 | 実行ボタン |
| --- | --- | --- | --- |
| 退会 | アプリから退会しますか | ログイン情報が削除されます。常備食と買い物リストはご家族に残ります。 | 退会する |

管理者が退会しようとしたが他のメンバーが残っている場合、[メンバーと家族グループ画面の「脱退できないときの表示」](14_メンバーと家族グループ.md#3-脱退できないときの表示)と同じ考え方で、文言の「脱退」を「退会」に置き換えて表示し、実行させない。
