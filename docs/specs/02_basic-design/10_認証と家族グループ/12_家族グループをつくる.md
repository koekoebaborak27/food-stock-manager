# 家族グループをつくる画面

## 1. 表示・操作

| 項目 | 内容 |
| --- | --- |
| 入力欄 | 家族グループの名前（1行テキスト、必須、20文字以内） |
| 保存ボタン | 「作成する」（[02_API.md](02_API.md) の `POST /api/households`） |
| 保存後 | 作成した利用者を管理者として登録し、常備食リストへ遷移する |

## 2. 入力チェック

[00_画面共通.md 8](../00_共通/00_画面共通.md#8-入力チェックの出し方) の手順、文言は [03_共通文言.md 4](../00_共通/03_共通文言.md#4-入力チェック) から選ぶ。

| 項目 | 条件 | 文言 |
| --- | --- | --- |
| 名前 | 未入力 | 入力してください |
| 名前 | 21文字以上 | 20文字以内で入力してください |
