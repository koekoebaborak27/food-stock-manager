# ログイン画面

ヘッダーのメニューと下部タブは出さない（[00_画面共通.md 1](../00_共通/00_画面共通.md#1-画面の枠)）。

## 1. 表示・操作

| 項目 | 内容 |
| --- | --- |
| 表示 | アプリ名「おうちde常備食」、一行の説明「家族で常備食と買い物リストを共有します」、「Googleでログインする」ボタン |
| 操作 | ボタンを押すと Google の認可画面へ移る（[02_API.md](02_API.md) の `/api/auth/google`） |
| 遷移先 | ログイン成功時、家族グループに未所属なら [家族グループの選択画面](11_家族グループの選択.md)、所属済みなら常備食リストへ |

## 2. エラー文言

| 場面 | 出し方 | 文言 |
| --- | --- | --- |
| Googleログインに失敗した | 画面上部の帯（3秒で消える） | Googleへのログインに失敗しました。もう一度お試しください。 |
