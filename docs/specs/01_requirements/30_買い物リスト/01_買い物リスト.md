# 買い物リスト

## 1. この機能の目的

切らした食品と買う予定の商品を家族で共有し、買ってきた物を手入力し直さずに常備食へ戻せる状態をつくること。

## 2. 対象範囲

買い物リストへの追加、未購入と購入済みの切り替え、購入済みの一括削除、購入済みから常備食への登録。

## 3. 買い物リストの商品が持つ情報

| 項目 | 必須 | 内容 |
| --- | --- | --- |
| 商品名 | 必須 | 買う物の呼び名 |
| 購入状態 | 必須 | 未購入 または 購入済み |
| 元の常備食 | 任意 | 常備食から追加された場合に、その食品を指す |
| 追加者・追加日時 | 自動 | 追加した利用者と日時 |

- 数量とメモを持たせないこと。商品名だけで運用すること。

## 4. 機能一覧

### 4.1 一覧

- 未購入の商品を上部に一覧で表示すること。
- 購入済みの商品は折りたたんで表示すること。件数を示し、押すと開けること。
- 商品が1件もないときは、空であることと追加を促す案内を表示すること。
- 引き下げ操作で再読込できること。

### 4.2 商品の追加

商品を追加する経路を2つ提供すること。

1. 常備食の詳細から追加する。食品名を商品名として引き継ぎ、元の常備食を記録すること。
2. 常備食の残数が0になったときのシートから追加する。同じく食品名と元の常備食を引き継ぐこと。
3. 買い物リストの画面で商品名を直接入力して追加する。元の常備食は持たないこと。

- 追加しようとした商品名が、すでに未購入として存在する場合は追加しないこと。すでにリストにある旨を伝えること。
- 購入済みに同じ商品名がある場合は、重複とみなさず追加すること。

### 4.3 購入状態の切り替え

- チェック操作で、未購入から購入済みへ移せること。
- 購入済みから未購入へ戻せること。
- 購入済みの商品をまとめて削除できること。削除前に確認すること。

### 4.4 購入済みから常備食への登録

未購入から購入済みへ切り替えた時点で、常備食へ戻すかどうかを1件ごとに確認すること。

- 確認では、常備食へ戻すかどうかと、保存区分を選ばせること。保存区分は冷蔵・冷凍・常温の3つから1タップで選べるようにすること。
- 元の常備食がある場合、保存区分の初期値をその食品の保存区分とすること。
- 元の常備食がない場合、保存区分の初期値を「冷蔵」とすること。
- 戻すことを選んだ場合、次のとおり登録すること。
  - 元の常備食が存在し、まだ使い切られていない場合は、その食品の残数を1増やすこと。
  - 元の常備食が存在しない、または使い切られている場合は、商品名を食品名として新しく登録すること。残数は1、期限は未設定、単位は未選択とすること。
- 期限と残数をこの場で入力させないこと。あとから常備食の編集画面で更新すること。
- 戻さないことを選んだ場合、購入済みへ移すだけとし、常備食には何もしないこと。

### 4.5 家族への反映

- 家族の変更は、画面を開いたとき、引き下げ操作をしたとき、自分が操作したときに再読込して反映すること。
- 開いている画面を自動で更新し続けないこと。

## 5. 権限

世帯に所属する利用者は全員、商品の追加・購入状態の切り替え・削除ができること。追加者以外による操作を妨げないこと。

## 6. 例外時の扱い

| 状況 | 扱い |
| --- | --- |
| 商品名が未入力 | 追加させないこと |
| 同じ商品名が未購入にすでにある | 追加せず、すでにリストにある旨を伝えること |
| 常備食へ戻す確認で保存区分が未選択 | 初期値のまま登録すること |
| 常備食へ戻す先の食品が他の利用者に削除されていた | 新しい常備食として登録すること |
| 購入済みの一括削除で対象が0件 | 操作を表示しないこと |
| 通信できない | 操作をさせず、接続が必要である旨を表示すること |

## 7. この機能で提供しないこと

- 数量・単位・メモの入力。
- リアルタイムでの共有。再読込での反映とすること。
- 購入済みへの切り替えを、確認なしで常備食へ反映すること。
- 複数の商品をまとめて常備食へ戻すこと。1件ごとの確認とすること。
- 買い物リストの並び替え、カテゴリ分け、店舗別の管理。
