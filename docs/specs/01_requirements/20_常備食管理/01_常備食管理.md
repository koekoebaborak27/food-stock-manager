# 常備食管理

## 1. この機能の目的

家にある食品と残数を家族で共有し、期限が近い食品に気づける状態をつくること。

## 2. 対象範囲

常備食の一覧、検索、並び替え、登録、編集、詳細、削除、残数の増減、消費済にすること、消費済リストからの再登録。

## 3. 常備食が持つ情報

| 項目 | 必須 | 内容 |
| --- | --- | --- |
| 食品名 | 必須 | 食品の呼び名 |
| 保存区分 | 必須 | 冷蔵・冷凍・常温のいずれか1つ |
| 残数 | 必須 | 0以上99以下の整数。初期値は1 |
| 単位 | 任意 | 個・袋・パック・食分・本・ごと のいずれか1つ。未選択でよい |
| 期限 | 任意 | 日付。時刻は持たない |
| 作り置き | 任意 | 家で作った作り置きであることを表す |
| メモ | 任意 | 自由記述 |
| 作成者・作成日時 | 自動 | 登録した利用者と日時 |
| 更新者・更新日時 | 自動 | 最後に更新した利用者と日時 |

- 残数に小数を使わせないこと。半端な残りは単位を「食分」にして表すこと。
- 単位が未選択のときは、残数の数字だけを表示すること。
- 作成日・購入日を利用者に入力させないこと。作成日時の自動記録で代えること。

## 4. 機能一覧

### 4.1 一覧

一覧をアプリのメイン画面とすること。

- 画面上部の構成を、ヘッダー・保存区分タブ・期限注意バー・カードの順とすること。フィルタを画面の上半分に積み上げないこと。
- ヘッダーには世帯名、検索アイコン、メニューを置くこと。
- 保存区分タブは「すべて / 冷蔵 / 冷凍 / 常温」の4つを1段で常に表示すること。
- 期限注意バーは、期限切れまたは今日・明日が期限の食品がある場合にだけ1行で表示すること。押すとその食品だけに絞り込めること。
- 食品はカード形式で表示すること。カードには食品名、保存区分、残数と単位、期限の状態、作り置きのタグを表示すること。
- カードから残数を増減できること。詳細を開かずに操作できること。
- カードから削除できること。削除の手順は「4.8 削除」のとおりとすること。
- カードから買い物リストへ追加できること。詳細を開かずに操作できること。追加しても常備食はそのまま残すこと。
- カードの食品名と同じ行の右端に、カートとゴミ箱のアイコンをこの順で並べること。残数の増減ボタンはカードの下段に置き、これらと離すこと。
- 買い物リストへ追加したときは画面を移さず、追加したことを画面下部の短い帯で伝えること。
- カードを押すと詳細へ進めること。
- 画面右下に丸い追加ボタンを置き、登録画面へ進めること。
- 引き下げ操作で再読込できること。
- 食品が1件もないときは、空であることと最初の登録を促す案内を表示すること。

### 4.2 検索

- ヘッダーの検索アイコンを押すと入力欄が現れること。検索欄を常に表示しないこと。
- 食品名で絞り込めること。
- 検索は選択中の保存区分タブの中で行うこと。
- メモを検索の対象としないこと。一覧のカードにメモを表示しないため、絞り込まれた理由が画面から読み取れなくなるのを避けること。

### 4.3 並び替え

- 既定の並び順を「期限が近い順」とすること。期限が未設定の食品は最後に並べること。
- 並び替えとして「追加順（新しい順）」と「名前順」を選べること。
- 並び替えの操作はメニューに収め、一覧の上部を占有しないこと。

### 4.4 期限の状態表示

期限の状態を4段階で表すこと。色だけでなく文言とアイコンでも区別できるようにすること。

| 状態 | 条件 | 表示する文言の例 |
| --- | --- | --- |
| 期限切れ | 期限が今日より前 | 「期限切れ（3日前）」 |
| 今日・明日 | 期限が今日または明日 | 「今日まで」「明日まで」 |
| 3日以内 | 期限が2日後から3日後 | 「あと3日」 |
| 通常 | 期限が4日後以降 | 「9/12まで」 |
| 表示なし | 期限が未設定 | 期限を表示しないこと |

- 期限切れの食品を自動で削除しないこと。
- 期限切れの食品を一覧から隠さないこと。

### 4.5 登録と編集

- 登録と編集は同じ画面を使うこと。
- 入力する項目は「3. 常備食が持つ情報」のとおりとすること。
- 期限はカレンダーから日付を選ぶこと。
- 保存すると一覧へ戻ること。
- 登録時、同じ世帯に同じ食品名がすでにある場合は、その旨を伝えること。ただし登録は妨げないこと。同名の食品をまとめないこと。
- 入力を取りやめて一覧へ戻れること。

### 4.6 詳細

- 食品名、保存区分、残数と単位、期限、作り置き、メモを表示すること。
- 作成者と作成日時、更新者と更新日時を画面下部に表示すること。
- 編集へ進めること。
- 削除できること。
- 買い物リストへ追加できること。
- 残数を増減できること。

### 4.7 残数の増減と消費済

- 一覧と詳細のどちらからも残数を1ずつ増減できること。
- 残数を0にしたとき、画面下部からシートを表示し、次の3つから選ばせること。
  - 消費済にする
  - 消費済にして、買い物リストに追加する
  - そのままにする
- 「そのまま」を選んだ食品は、残数0のまま一覧に残すこと。切らしていることが分かる表示を付けること。
- 残数を0未満にしないこと。
- 消費済にした食品は一覧から外すこと。データは削除しないこと。

### 4.8 削除

- 一覧のカードと詳細のどちらからも削除できること。
- 一覧では、カードの食品名と同じ行の右端にゴミ箱のアイコンを置くこと。残数の増減ボタンと押し間違えないよう、両者を離して配置すること。
- ゴミ箱のアイコンを赤で塗らないこと。一覧に赤が並ぶことを避け、赤は確認画面の削除ボタンにだけ使うこと。
- 削除前に確認すること。確認では、消費済リストにも残らないことと、食べ終えた場合は削除ではなく残数を0にすればよいことを伝えること。
- 削除した直後に「元に戻す」操作を提供すること。表示時間は5秒程度とすること。
- 削除した食品を一覧から外すこと。データは削除せず、消費済リストにも表示しないこと。

### 4.9 消費済リスト

- 消費済にした食品の一覧を表示すること。新しい順に並べること。
- 画面下部のタブから開けること。常備食リスト・買い物リストと同じ高さの導線に置くこと。
- 表示するのは食品名、保存区分、単位、消費済にした日付とすること。
- 消費済リストの食品から、同じ食品名・保存区分・単位を引き継いで常備食へ再登録できること。残数は1、期限は未設定として登録し、そのまま編集画面を開くこと。
- 消費済リストの食品から、買い物リストへ追加できること。食品名を商品名として引き継ぎ、元の常備食を記録すること。追加しても消費済リストからは外さないこと。
- 「常備食へ戻す」と「買い物リストへ追加する」の2つを、1件ずつの操作として並べて置くこと。
- 削除した食品を消費済リストに表示しないこと。
- 消費済リストから食品を消す操作は提供しないこと。

### 4.10 更新の競合

- 保存時に、他の利用者が先に更新していないかを更新日時で確認すること。
- 先に更新されていた場合は保存せず、他の人が更新した旨を伝えて再読込を促すこと。
- 残数の増減はこの確認の対象外とすること。「1増やす」「1減らす」という差分として扱い、2人が同時に1ずつ減らした場合に2減ること。

## 5. 権限

世帯に所属する利用者は全員、常備食の登録・編集・削除・残数の増減・消費済リストの閲覧と再登録ができること。作成者以外による編集と削除を妨げないこと。

## 6. 例外時の扱い

| 状況 | 扱い |
| --- | --- |
| 食品名が未入力 | 保存させないこと |
| 保存区分が未選択 | 保存させないこと。初期値を「冷蔵」とすること |
| 残数が0未満、または100以上 | 保存させないこと |
| 期限に過去の日付が入力された | 保存を認めること。期限切れとして表示すること |
| 同じ食品名がすでにある | 伝えたうえで登録を認めること |
| 他の利用者が先に更新していた | 保存せず、再読込を促すこと |
| 表示中の食品が他の利用者に削除されていた | 一覧へ戻し、削除された旨を伝えること |
| 通信できない | 操作をさせず、接続が必要である旨を表示すること |

## 7. この機能で提供しないこと

- 食品の写真。
- 残数の小数入力。
- 期限の時刻指定、賞味期限と消費期限の区別。
- 削除した食品の履歴表示と復元。削除直後の取り消しのみとすること。
- 同名食品の自動的なまとめ。
- 食品ごとのコメント、担当者の割り当て。
- 期限切れ食品の自動削除。
