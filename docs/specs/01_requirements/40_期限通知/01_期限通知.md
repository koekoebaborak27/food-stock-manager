# 期限通知

## 1. この機能の目的

アプリを開かなくても、期限が迫った食品に家族が気づける状態をつくること。

## 2. 対象範囲

プッシュ通知の許可、通知時刻の設定、1日1回の通知配信。

## 3. 機能一覧

### 3.1 通知の許可

- 利用者ごとに通知を受け取るかどうかを設定できること。初期状態は受け取らないこと。
- 通知を有効にするとき、端末に通知の許可を求めること。
- 端末側で通知が許可されていない場合は、その旨と対処を表示すること。
- iOSでは、ホーム画面へ追加したうえでないと通知を受け取れないため、その案内を表示すること。

### 3.2 通知の配信

- 1日に1回だけ配信すること。
- 配信する内容は、期限切れ・今日が期限・明日が期限の食品の合計件数をまとめた1通とすること。
- 対象となる食品が1件もない日は配信しないこと。
- 通知を押すと、常備食リストの期限が近い食品に絞り込んだ状態で開くこと。
- 配信対象は、その世帯に所属し通知を有効にしている利用者全員とすること。

### 3.3 通知時刻

- 通知を送る時刻を世帯単位で設定できること。
- 初期値を8時00分とすること。
- 世帯に所属する利用者は全員、時刻を変更できること。

## 4. 権限

世帯に所属する利用者は全員、通知時刻を変更できること。通知を受け取るかどうかは利用者ごとに設定すること。

## 5. 例外時の扱い

| 状況 | 扱い |
| --- | --- |
| 端末が通知を許可していない | 有効にできない旨と、端末の設定から許可する方法を伝えること |
| ホーム画面へ追加していないiOS端末 | 追加が必要である旨を伝えること |
| 配信に失敗した | 再送しないこと。翌日の配信に任せること |
| 購読情報が無効になっていた | その購読情報を削除し、次回以降配信しないこと |

## 6. この機能で提供しないこと

- 食品1件ごとの個別通知。
- 買い物リストが更新されたときの通知。
- 1日に複数回の配信。
- 利用者ごとに異なる通知時刻の設定。
- メールによる通知。
