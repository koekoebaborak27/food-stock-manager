# 認証と家族グループ

## 1. この機能の目的

家族が同じ世帯に集まり、常備食と買い物リストを共有できる状態をつくること。

## 2. 対象範囲

Googleログイン、利用者の初回登録、世帯の作成、招待コードによる参加、メンバーの表示、脱退、除名、退会、世帯の削除。

## 3. 機能一覧

### 3.1 Googleログイン

- Googleアカウントによるログインだけを提供すること。
- ログイン画面には、アプリ名「おうちde常備食」と一行の説明、Googleでログインするボタンを置くこと。
- ログイン状態を保持し、次回起動時にログイン画面を出さないこと。
- ログアウトできること。

### 3.2 利用者の初回登録

- 初めてログインした利用者を、Googleアカウントの識別子で新規の利用者として登録すること。
- 表示名・メールアドレス・アイコンURLをGoogleアカウントから取得して保持すること。
- 表示名は利用者が変更できること。

### 3.3 世帯への参加

- どの世帯にも所属していない利用者には、ログイン直後に必ず選択画面を表示すること。選択肢は「家族グループをつくる」と「招待コードで参加する」の2つとすること。
- 世帯に所属しないまま常備食一覧へ進めないこと。
- 選択画面には、現在ログインしているGoogleアカウントの表示名とメールアドレスを表示すること。
- 選択画面には「すでに家族グループを使っている方は、以前と同じGoogleアカウントでログインしてください」という案内を表示すること。

#### 家族グループをつくる

- 世帯の名前を入力して作成すること。名前は「やまだ家」のような呼び名とすること。
- 作成した利用者を、その世帯の管理者とすること。

#### 招待コードで参加する

- 招待コードを入力して、対応する世帯に参加すること。
- 参加した利用者は一般メンバーとすること。
- 誤ったコード、期限切れのコード、すでに使われたコードは参加させないこと。

### 3.4 招待コードの発行

- 世帯に所属する利用者は全員、招待コードを発行できること。管理者に限定しないこと。
- 発行したコードの有効期限は発行から7日間とすること。
- コードは画面に表示し、コピーできること。
- 発行済みのコードを再表示できること。期限が切れている場合は、その場で発行し直せること。

### 3.5 所属のルール

- 1人の利用者が同時に所属できる世帯は1つとすること。
- すでに世帯に所属している利用者が別の招待コードを使った場合、現在の世帯を脱退したうえで新しい世帯に参加すること。脱退になる旨を確認してから実行すること。

### 3.6 メンバーの表示

- 世帯に所属するメンバーの一覧を表示すること。表示するのは表示名とアイコン、管理者かどうか。
- メールアドレスは、本人以外には表示しないこと。

### 3.7 脱退・除名・退会・世帯の削除

- 利用者は自分の意思で世帯を脱退できること。確認してから実行すること。
- 管理者は他のメンバーを除名できること。確認してから実行すること。管理者は自分自身を除名できないこと。
- 利用者はアプリから退会できること。確認してから実行すること。
- 管理者は世帯を削除できること。確認してから実行すること。世帯を削除すると、その世帯の常備食・買い物リスト・使い切り履歴をすべて削除すること。
- 管理者が脱退または退会しようとした場合、世帯に他のメンバーがいるときは実行させないこと。世帯を削除するか、他のメンバーの除名を先に行うよう案内すること。
- 管理者が最後の1人である世帯で脱退・退会した場合、その世帯を併せて削除すること。

### 3.8 脱退・退会時のデータの扱い

- 常備食・買い物リスト・使い切り履歴は世帯に属するものとして残すこと。脱退した利用者が登録したものも削除しないこと。
- 脱退・退会した利用者の表示名・メールアドレス・アイコンURLを削除すること。
- 作成者・更新者としてその利用者を表示していた箇所は「退会したメンバー」と表示すること。

[プロダクト共通要件の権限](../00_共通/01_プロダクト共通.md#5-権限) に従うこと。

## 5. 例外時の扱い

| 状況 | 扱い |
| --- | --- |
| Googleログインに失敗した | ログイン画面にとどまり、もう一度試すよう促すこと |
| 招待コードが存在しない | 参加させず、コードを確認するよう促すこと |
| 招待コードの有効期限が切れている | 参加させず、家族に再発行を頼むよう促すこと |
| 世帯名が未入力 | 作成させないこと |
| 管理者が他のメンバーを残したまま脱退・退会しようとした | 実行させず、理由と対処を伝えること |
| 除名・世帯削除を一般メンバーが実行しようとした | 実行させないこと。画面にも操作を表示しないこと |

## 6. この機能で提供しないこと

- パスワード認証、メールアドレス認証、Google以外の外部サービスによる認証。
- 招待リンク、メールアドレスを指定した招待。
- 複数の世帯への同時所属と世帯の切り替え。
- 管理者の譲渡、複数の管理者。
- アカウントの引き継ぎコード。機種変更は、同じGoogleアカウントでのログインで対応すること。
